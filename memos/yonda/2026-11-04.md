#server
**RPC(Remote Procedure Call)**は、別のコンピューター(サーバー)にある関数を、手元の関数と同じように呼び出す仕組みです。

REST との違い

REST では、「どの URL に、どの HTTP メソッドでリクエストを送るか」を設計し、呼び出す側もそれを意識します。

```
// クライアント側
const res = await fetch("/api/books/123", {
  method: "PATCH",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ readDate: "2026-10-15", memo: "面白かった" }),
});
const book = await res.json(); // 中身の型は自分で付ける必要がある
```

RPC では、関数を呼ぶだけで済みます。通信の細かい部分は、フレームワークが裏で処理してくれます。

```
// サーバー側(server/functions/books.ts)
export const updateBook = createServerFn({ method: "POST" })
  .inputValidator(updateBookInput)
  .handler(async ({ data }) => { /* DB を更新 */ });
```
