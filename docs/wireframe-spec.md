# 読書記録アプリ ワイヤーフレーム仕様書(Figma 指示用)

## 0. 前提

| 項目 | 内容 |
|---|---|
| 対象 | 自分専用の読書記録 PWA |
| 想定端末 | スマホ中心(モバイルファースト) |
| 基準フレーム | 375 × 667 px(iPhone SE 第2世代) |
| セーフエリア | 上 20px(ステータスバー)、下 0px(ホームインジケーターなし) |
| 最小対応幅 | 375px(これより狭い画面は考慮しない) |
| UIライブラリ | Chakra UI(v3) |
| 雰囲気 | シンプル(無彩色ベース + オレンジ 1 色) |
| テーマ | ライト / ダーク(手動切替)。全画面を両テーマで作成 |
| 言語 | 日本語 |

## 1. デザイントークン

### 1-1. カラー(セマンティック)

| トークン | ライト | ダーク | 用途 |
|---|---|---|---|
| `bg` | 白 | 近黒(#0F0F10 前後) | 画面背景 |
| `bg.subtle` | 薄グレー | ダークグレー | カード背景、入力欄 |
| `fg` | 濃グレー | ほぼ白 | 本文 |
| `fg.muted` | 中グレー | 明るめグレー | 補助テキスト(著者、日付) |
| `border` | 薄グレー | ダークグレー | 区切り線、カード枠 |
| `accent` | orange.500 | orange.400 | 主ボタン、アクティブタブ、リンク |
| `accent.subtle` | orange.50 | orange.900 系(低彩度) | 選択状態の背景 |
| `danger` | red.500 | red.400 | 削除 |
| `warning` | yellow 系 | yellow 系(暗背景用) | オフラインバナー |

※ アクセントはオレンジ。白文字ボタンのコントラスト比 4.5:1 以上を確認し、不足する場合は orange.600 を使用する。

### 1-2. タイポグラフィ

| 用途 | サイズ | ウェイト |
|---|---|---|
| 画面タイトル | 20px | Bold |
| カードタイトル | 16px | Semibold |
| 本文・入力 | 16px | Regular |
| 補助テキスト | 14px | Regular |
| キャプション | 12px | Regular |

フォント: システムフォント(日本語は端末標準)

### 1-3. スペーシング・形状

| 項目 | 値 |
|---|---|
| 画面左右マージン | 16px |
| カード間隔 | 12px |
| カード内余白 | 12px |
| 角丸 | カード 8px、ボタン・入力 8px |
| 影 | なし(枠線で区切る) |
| タップ領域 | 最小 44 × 44px |

## 2. 共通コンポーネント

| # | コンポーネント | 仕様 |
|---|---|---|
| C1 | ヘッダー | 高さ 56px。左: 画面タイトル(詳細画面は戻るボタン)、右: テーマ切替アイコン |
| C2 | 下部タブバー | 高さ 56px + 下セーフエリア。タブ 2 つ(本棚 / 検索)。アイコン + ラベル。アクティブは `accent` |
| C3 | オフラインバナー | ヘッダー直下に固定。黄系。「オフラインです。検索・登録・編集はできません」。通常時は非表示 |
| C4 | 本カード | 下記 2-1 参照 |
| C5 | 主ボタン | 塗りつぶし `accent`、白文字、高さ 44px |
| C6 | 副ボタン | 枠線のみ、高さ 44px |
| C7 | 危険ボタン | 枠線 `danger`、文字 `danger`、高さ 44px |
| C8 | 確認ダイアログ | 画面中央、背景を暗転。タイトル、説明、キャンセル(副)、実行(危険) |
| C9 | トースト | 画面上部に表示、3 秒で消える |
| C10 | 空状態 | アイコン、見出し、説明、行動ボタン(縦中央揃え) |
| C11 | 「さらに表示する」ボタン | 一覧の末尾に全幅の副ボタンで配置(高さ 44px)。表示条件は「未表示の件が残っている場合」(11 件以上のとき)。状態は 通常(「さらに表示する」)/ 読み込み中(ボタン無効化 + スピナー + 「読み込み中...」)/ 失敗(エラー文 + 「再試行」)/ 全件表示後(ボタンを消し、「これ以上ありません」を `fg.muted` 12px で表示) |

### 2-1. 本カード(C4)

```
┌─────────────────────────────────┐
│ ┌────┐  タイトル(最大2行)       │
│ │表紙│  著者名(1行、省略)       │
│ │ 画像│  読了日: 2026/10/15      │
│ └────┘                           │
└─────────────────────────────────┘
```

| 要素 | 仕様 |
|---|---|
| 表紙画像 | 幅 64px × 高さ 96px(2:3)、角丸 4px |
| 表紙なし | グレー背景に本アイコンのプレースホルダー |
| タイトル | 16px Semibold、最大 2 行で省略 |
| 著者 | 14px `fg.muted`、1 行で省略 |
| 読了日 | 14px `fg.muted`、「読了日: YYYY/MM/DD」 |
| 状態 | 通常 / タップ時(`bg.subtle`)/ 登録済み(検索結果のみ) |
| タップ | 詳細画面へ遷移 |

## 3. 画面別ワイヤーフレーム

### 画面 1: 本棚(`/`)

```
┌───────────────────────────┐
│ 本棚                  ☾   │ ← C1 ヘッダー
├───────────────────────────┤
│ [オフラインバナー]        │ ← C3(オフライン時のみ)
├───────────────────────────┤
│ 並び替え [読了日が新しい順▼]│ ← ネイティブセレクト
│                           │
│ ┌───────────────────────┐ │
│ │ 本カード              │ │
│ └───────────────────────┘ │
│ ┌───────────────────────┐ │
│ │ 本カード              │ │
│ └───────────────────────┘ │
│            ⋮              │
├───────────────────────────┤
│  📚 本棚      🔍 検索     │ ← C2 タブバー
└───────────────────────────┘
```

| 要素 | 仕様 |
|---|---|
| 並び替え | 全幅のセレクト。初期値「読了日が新しい順」 |
| 並び替え選択肢 | 読了日が新しい順 / 古い順 / 著者順 / 登録日が新しい順 / 古い順 |
| 一覧 | カードを縦 1 列。縦スクロール。初回は 10 件まで表示 |
| 追加表示 | 11 件以上ある場合のみ、末尾に C11「さらに表示する」を配置。押すと次の 10 件を追加表示(以降も同様) |
| 追加表示の遅延 | ボタン押下後、少し待ってから表示(300〜500ms 程度)。その間 C11 は「読み込み中」。連打は無効化で防ぐ |
| 並び替えとの関係 | 全件を並び替えた上で、先頭から 10 件ずつ表示。並び替え変更時は先頭 10 件に戻る |
| 全件表示後 | ボタンを消し、「これ以上ありません」を表示 |
| 件数表示 | 並び替えの右に「全 N 冊」(12px)。N は表示件数ではなく登録総数 |
| 空状態 | C10。「まだ本がありません」「検索から本を追加しましょう」+ 主ボタン「本を検索する」 |
| オフライン | バナー表示のみ。閲覧・ソートは通常どおり可能 |

**作成するバリエーション:** 通常(10 件 + 「さらに表示する」、ライト/ダーク)、10 件以下(ボタンなし)、追加読み込み中、全件表示後(これ以上ありません)、空状態、オフライン、初回読み込み中(スケルトンカード 3 枚)

### 画面 2: 検索(`/search`)

```
┌───────────────────────────┐
│ 検索                  ☾   │
├───────────────────────────┤
│ [オフラインバナー]        │
├───────────────────────────┤
│ ┌───────────────┐ [検索]  │ ← 入力 + 主ボタン
│ │ タイトル・著者 │         │
│ └───────────────┘         │
│                           │
│ ┌───────────────────────┐ │
│ │ 表紙 タイトル          │ │
│ │      著者              │ │
│ │              [登録]    │ │ ← 結果カード
│ └───────────────────────┘ │
│ ┌───────────────────────┐ │
│ │ 表紙 タイトル          │ │
│ │      著者  [登録済み]  │ │
│ └───────────────────────┘ │
├───────────────────────────┤
│  📚 本棚      🔍 検索     │
└───────────────────────────┘
```

| 要素 | 仕様 |
|---|---|
| 検索入力 | プレースホルダー「タイトル・著者名で検索」。キーボードの検索キーで実行 |
| 結果カード | C4 をベースに、右下に登録ボタンを追加(副ボタン、小サイズ、高さ 44px) |
| 登録済み | ボタンを無効化し「登録済み」表示(`fg.muted`) |
| 登録操作 | ボタン押下で登録、トースト「登録しました」。読了日は登録日が初期値 |
| 結果件数 | 初回は 10 件まで表示 |
| 追加表示 | 次の 10 件がある場合のみ、末尾に C11「さらに表示する」を配置。押すと次の 10 件を追加表示(以降も同様) |
| 追加表示の遅延 | ボタン押下後、少し待ってから表示(300〜500ms 程度)。その間 C11 は「読み込み中」。連打は無効化で防ぐ |
| 全件表示後 | ボタンを消し、「これ以上ありません」を表示 |
| 状態 | 初期(説明文のみ)/ 読み込み中 / 結果あり / 追加読み込み中 / 追加読み込み失敗(再試行)/ 全件表示後 / 0 件 / 通信エラー(再試行ボタン) |
| オフライン | 入力欄とボタンを無効化。入力欄の下に「オフラインのため検索できません」 |

**作成するバリエーション:** 初期、読み込み中、結果あり(10 件 + 「さらに表示する」)、追加読み込み中、追加読み込み失敗、全件表示後、0 件、通信エラー、オフライン(各ライト/ダーク)

### 画面 3: 本の詳細・編集(`/books/$id`)

```
┌───────────────────────────┐
│ ←  本の詳細           ☾   │
├───────────────────────────┤
│ [オフラインバナー]        │
├───────────────────────────┤
│        ┌────────┐         │
│        │ 表紙   │         │ ← 幅 120 × 高さ 180
│        │ 画像   │         │
│        └────────┘         │
│  タイトル(複数行可)      │
│  著者名                   │
│                           │
│ 読了日                    │
│ ┌───────────────────────┐ │
│ │ 2026/10/15        📅  │ │ ← 日付入力(必須)
│ └───────────────────────┘ │
│                           │
│ 感想メモ                  │
│ ┌───────────────────────┐ │
│ │                       │ │
│ │                       │ │ ← テキストエリア(複数行)
│ └───────────────────────┘ │
│                           │
│ [        保存        ]    │ ← 主ボタン(全幅)
│ [        削除        ]    │ ← 危険ボタン(全幅)
├───────────────────────────┤
│  📚 本棚      🔍 検索     │
└───────────────────────────┘
```

| 要素 | 仕様 |
|---|---|
| 戻るボタン | 左上。本棚へ戻る |
| 書誌情報 | 表紙、タイトル、著者(編集不可) |
| 読了日 | 必須。ネイティブ日付入力。空にして保存するとエラー「読了日を入力してください」 |
| 感想メモ | 最小高さ 160px。文字数カウンターは不要 |
| 保存 | 成功時にトースト「保存しました」。未変更時は無効化 |
| 削除 | C8 ダイアログ「この本を削除しますか?」「感想メモも削除されます。元に戻せません。」 |
| オフライン | 日付・メモは閲覧のみ(無効化)。保存・削除ボタンも無効化し、バナーで理由を表示 |

**作成するバリエーション:** 通常、読了日エラー、削除確認ダイアログ、オフライン(各ライト/ダーク)

## 4. 画面遷移

| 遷移元 | 操作 | 遷移先 |
|---|---|---|
| 本棚 | カードをタップ | 本の詳細 |
| 本棚(空) | 「本を検索する」 | 検索 |
| 検索 | 登録 | 同画面(登録済み表示) |
| 本の詳細 | 戻る | 本棚 |
| 本の詳細 | 削除を実行 | 本棚(トースト「削除しました」) |
| 全画面 | タブバー | 本棚 / 検索 |

## 5. Figma 作成の指示

| 項目 | 指示 |
|---|---|
| ページ構成 | 「Tokens」「Components」「Screens-Light」「Screens-Dark」 |
| フレーム | 375 × 667、画面ごとに 1 フレーム。状態バリエーションは横に並べる。一覧は 667px を超える長さのスクロール前提で、10 件分の縦長フレームも 1 つ作成 |
| 命名規則 | `画面名/状態/テーマ`(例: `Shelf/Empty/Dark`) |
| レイアウト | Auto Layout を使用。余白は 4 の倍数 |
| カラー | Variables でセマンティックトークンを定義し、ライト/ダークをモードで切替 |
| コンポーネント | C1〜C11 をコンポーネント化。状態は Variants で管理 |
| 忠実度 | 低〜中(グレースケール + アクセントのみ。装飾なし) |
| 画像 | 表紙はグレーのプレースホルダー |
| ダミーデータ | 本 5 冊程度(タイトルの長短、著者名の長短、表紙なしを含める) |

## 6. 未決事項

| 論点 | 案 |
|---|---|
| アプリ名・ロゴ | 仮名のまま進めるか、別途決める |
| PWA アイコン | WF 完了後に作成 |
| 検索結果の取得件数 | 10 件ずつ(Google Books API の maxResults=10 と startIndex で追加取得) |
| 追加表示の待ち時間 | 300〜500ms を初期案とし、実機で調整 |
| 「さらに表示する」の出し分け(検索) | Google Books API の総件数(`totalItems`)は不正確なことがあるため、次の取得結果が 0 件になった時点でボタンを消す案 |
